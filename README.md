Self-taught hobbyist programmer from Poland. I wrote my first lines of code at 9 out of curiosity and never really stopped.

I learn by building: if I don't understand something, I take it apart and make my own version. Most of what I write ends up in one of these areas: automation, Linux, cybersecurity, self-hosting, and local AI.
